Building LabStreamingLayer Full Tree
####################################

The `labstreaminglayer repository <https://github.com/sccn/labstreaminglayer>`__ collects the apps as git
submodules. Build each app from its own repository (see :doc:`app_build`) and get liblsl from a release
or with CMake's FetchContent (see :liblsl:`Using liblsl in your project <guide/linking.html>`).
