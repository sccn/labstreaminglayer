CMake
#####

LSL is built with `CMake <https://cmake.org>`__. See the
`CMake documentation <https://cmake.org/cmake/help/latest/>`__ for a general introduction, and
:liblsl:`Building liblsl <guide/building.html>` and :liblsl:`Using liblsl in your project <guide/linking.html>`
for liblsl's options and CMake package.
